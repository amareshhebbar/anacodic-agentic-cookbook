# Experiments

Attempts at a benchmark. Some will win and get promoted into `01-modules/`;
most won't, and that's fine — a documented attempt that didn't beat the
number is still useful to the next person who tries.

One folder per contribution, named `<your-name>-<topic>`, e.g.:

```
02-experiments/
├── alice-handwriting-ocr/
├── bob-table-fidelity/
```

Each folder should contain its own notebook(s), a short `README.md` stating
what you tried and what it scored against the relevant benchmark in
`04-benchmarks/`, and nothing that belongs to someone else's folder.

**Before you write a notebook**, read
[NOTEBOOK_STANDARD.md](NOTEBOOK_STANDARD.md) — it's a different cell rhythm
than `01-modules/` uses, on purpose, and it's easier to write that way from
the first cell than to restructure afterward.

See [CONTRIBUTING.md](../CONTRIBUTING.md) for the fork-and-PR workflow and the
promotion path into `01-modules/`.
