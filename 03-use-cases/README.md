# Use cases

Finished, demoable applications built on top of the five stages. Unlike
`02-experiments/` (attempts, may not work), a use case here should run start
to finish and show something real.

One folder per use case, named for what it does, e.g.:

```
03-use-cases/
├── clinical-evidence-search/
├── exam-script-grading/
```

Each folder should be runnable on its own: its own `README.md`, its own
`requirements.txt`, and no partner or student data of any kind.

See [CONTRIBUTING.md](../CONTRIBUTING.md) for the fork-and-PR workflow.
